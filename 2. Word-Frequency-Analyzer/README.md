# 📊 Word Frequency Analyzer

An interactive NLP application built using **Python**, **NLTK**, **Scikit-learn**, **Pandas**, **Matplotlib**, and **Streamlit**.

The application allows users to analyze text using **Bag of Words**, **N-grams**, and **Word Frequency Visualization**.

---

## 🚀 Features

- 📄 User text input
- 📊 Bag of Words (BoW) matrix
- 🔤 Unigrams, Bigrams & Trigrams
- 📈 Word Frequency Visualization
- ⚡ Interactive Streamlit interface

---

## 🛠️ Technologies Used

- Python
- NLTK
- Scikit-learn
- Pandas
- Matplotlib
- Streamlit

## ▶️ Installation

Clone the repository

```bash
git clone https://github.com/Himanshu-97-cloud/Word-Frequency-Analyzer.git
```

Move into the project

```bash
cd Word-Frequency-Analyzer
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
streamlit run app.py
```
